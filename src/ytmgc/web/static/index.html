1Connecter le compte

Compte connecté ().

Si tu es déjà connecté à YouTube Music dans un navigateur, l'application reprend cette session. Rien à saisir.

Fiable sur Firefox, macOS et Linux. Sous Windows, Chrome chiffre ses cookies depuis la version 127 : préfère Firefox, ou une autre méthode.

L'application ouvre une fenêtre sur YouTube Music. Connecte-toi normalement : la fenêtre se referme d'elle-même une fois la session récupérée.

Google refuse parfois la connexion dans une fenêtre pilotée automatiquement. Si c'est le cas, utilise l'un des autres onglets.

Connexion par ton compte Google, sans dépendre d'un navigateur local. Il faut en revanche créer une fois un identifiant client OAuth : Google impose à chaque application de s'enregistrer.

  1. Ouvre console.cloud.google.com et crée un projet.
  2. Active l'API YouTube Data API v3 pour ce projet.
  3. Dans Identifiants, crée un ID client OAuth de type Téléviseurs et périphériques à saisie limitée.
  4. Recopie l'identifiant et le secret obtenus ci-dessous.

Ouvre ce lien, connecte-toi au compte YouTube voulu, puis reviens ici. La connexion se termine toute seule.

Méthode manuelle, à réserver aux cas où les autres échouent. Les étapes diffèrent selon le navigateur.

  1. Ouvre music.youtube.com dans Firefox, connecté à ton compte.
  2. Appuie sur F12. Un panneau s'ouvre en bas ou sur le côté : clique sur l'onglet Réseau.
  3. Laisse ce panneau ouvert et, dans la page YouTube Music, clique sur Bibliothèque (menu de gauche). Des dizaines de lignes apparaissent dans le panneau.
  4. Clic droit sur n'importe quelle ligne de cette liste → Copier (parfois nommé Copier la valeur) → « Copier comme cURL ».
  5. Colle le résultat ci-dessous, puis clique sur Connecter.
  1. Ouvre music.youtube.com dans Chrome ou Edge, connecté à ton compte.
  2. Appuie sur F12. Un panneau s'ouvre : clique sur l'onglet Network (ou Réseau).
  3. Laisse ce panneau ouvert et, dans la page YouTube Music, clique sur Bibliothèque (menu de gauche). Des dizaines de lignes apparaissent dans le panneau.
  4. Clic droit sur n'importe quelle ligne de cette liste → Copy → « Copy as cURL (bash) ». Si seul Copy as cURL est proposé, prends-le. Évite Copy as PowerShell.
  5. Colle le résultat ci-dessous, puis clique sur Connecter.

Le texte collé commence par curl et fait plusieurs milliers de caractères : c'est normal. L'application n'y garde que le cookie de session.

Aucune ligne n'apparaît ? L'inspecteur ne montre que ce qui se passe après son ouverture. Garde-le ouvert et clique dans la page YouTube Music : la liste se remplit. Ne mets aucun filtre.

« Aucun cookie trouvé » ? La ligne choisie n'était pas authentifiée. Recommence sur une autre ligne — celles dont le nom commence par browse, next ou guide conviennent toujours.

Ces en-têtes contiennent les identifiants de ta session. Ils ne sont écrits que dans le fichier local d'authentification et ne quittent jamais ta machine.

5Appliquer

Seules les playlists créées par cet outil sont modifiées. Les playlists que tu as faites toi-même ne sont jamais touchées.

Annuler

Supprime toutes les playlists générées par l'outil et rend le compte à son état initial. Les playlists personnelles sont conservées. Cette action est irréversible.
